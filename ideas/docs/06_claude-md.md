# CLAUDE.mdチラ見せ

## 概要

自分のCLAUDE.md設定を公開して解説

## CLAUDE.mdとは

- Claude Codeが読み込むプロジェクト固有の指示書
- プロンプトの一部として毎回読み込まれる
- チーム共通ルールを強制できる

## 配置場所と優先順位

```
1. プロジェクト/.claude/CLAUDE.md（最優先）
2. 親ディレクトリ/.claude/CLAUDE.md（再帰的）
3. ~/.claude/CLAUDE.md（グローバル）
```

## 自分のグローバルCLAUDE.md（366行）

### 言語設定

```markdown
**日本語での対応**
- すべてのやり取りを日本語で行ってください
- 技術的な内容も日本語で説明してください
```

### Gitポリシー（最重要）

```markdown
**絶対に`git add`を実行してはいけない**
- ユーザーが「git commit」と言った時、絶対に`git add`を実行しない
- ステージングされている変更のみでコミットする
- `git add`、`git add -A`、`git add .`など禁止
```

なぜ？ → 意図しないファイルをコミットさせない

### コミットメッセージ作成手順

```markdown
**コミットメッセージ作成時の必須手順**
- 必ず`git diff --cached`で変更内容を確認
- ブランチ名やファイル名からの推測ではなく実際の変更に基づく
- ステージングされていない変更は含めない
```

### 言語別開発ポリシー

#### Go言語

```markdown
- `cmd/` - 実行可能ファイル
- `handlers/` - HTTPリクエストハンドラ
- `models/` - データモデル
- `service/` - ビジネスロジック
```

#### Laravel/PHP

```markdown
- すべてのコマンドは必ずDockerコンテナ内で実行
- 正しい: `docker compose exec php php artisan migrate`
- 間違い: `php artisan migrate`
```

#### Terraform

```markdown
- `terraform init`は`make install`で実行
- 手動でterraformコマンドを直接実行しない
- Makefileで定義されたコマンドを使用
```

### コメント記述ルール

```markdown
**禁止される表現の例：**
- 「〜を駆逐」「〜を撲滅」などの過激な表現
- 「〜かもしれない」「〜だろう」などの曖昧な表現
- ユーモアや皮肉を含む表現

**許可されるコメントの例：**
- 技術的制約の説明：「# ECS Exec経由でRDS接続」
- 設定値の説明：「# RDS接続用の変数」
```

### 人名表記ポリシー

```markdown
**漢字表記が確実にわかる場合のみ漢字を使用**
- 悪い例：「石川正幸」（Masayuki Ishikawaとしか記載がない場合）
- 良い例：「Masayuki Ishikawa」（漢字が確認できない場合）
```

なぜ？ → AIが漢字を推測して間違えることがある

### 依存関係管理

```markdown
**brewで依存関係をインストールする前に、必ずMakefileを作成**
- 他の開発者が`make install`で同じ環境を再現できること
```

### セキュリティルール

```markdown
**Gitトラッキング状況の必須確認**
- ファイルを削除・変更する前に`git ls-files`で確認
- Gitで追跡されていないファイルは絶対に削除・変更しない
- 個人の`.env`ファイルは明示的に要求されない限り変更しない
```

## 効果があった設定

- git add禁止 → 事故防止に効果大
- 日本語強制 → 回答が安定
- Makefile強制 → 環境再現性向上

## 失敗した設定

- 細かすぎるルール → 守られないことも
- 矛盾するルール → 混乱の元
