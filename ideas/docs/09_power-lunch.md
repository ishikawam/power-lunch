# パワーランチとは

## 概要

バックエンドエンジニアチームの定期勉強会

## 基本情報

| 項目 | 内容 |
|------|------|
| 時間 | 12:00 - 13:00（1時間） |
| 形式 | 弁当持ち寄り + 発表 |
| 参加人数 | 最大8名程度 |
| 場所 | 会議室（スクリーン使用） |

## 目的

- チーム内の技術共有
- 各自の知見を共有
- コミュニケーション活性化
- 昼休みの有効活用

## 発表形式

### 時間配分（目安）

| 時間 | 内容 |
|------|------|
| 5分 | イントロ・自己紹介的な話 |
| 30-40分 | メイン発表 |
| 15-20分 | 質疑応答・ディスカッション |

### 発表スタイル

- スライドでもライブデモでもOK
- PCを持ち寄ってスクリーンに投影
- カジュアルな雰囲気で
