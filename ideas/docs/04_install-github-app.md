# /install-github-app 使ってみた

## 概要

Claude CodeのGitHub App連携機能

## 何ができるようになるか

- GitHubリポジトリとの深い連携
- Issue、PR、コードの直接操作
- GitHub Actions連携
- コードレビュー支援

## 設定方法

### 1. コマンド実行

```
/install-github-app
```

### 2. ブラウザで認証

- GitHubにリダイレクト
- Anthropic GitHub Appをインストール
- リポジトリへのアクセス権限を付与

### 3. 権限スコープ

- リポジトリの読み取り
- Issue/PRの作成・編集
- コードの読み取り

## 使える機能

### Issue操作

```
このリポジトリのIssue一覧を見せて
Issue #123 の内容を確認して
新しいIssueを作成して
```

### PR操作

```
PR #456 のレビューをして
PRを作成して
PR #456 にコメントして
```

### コード検索

```
このリポジトリで認証関連のコードを探して
最近の変更を確認して
```

## gh CLI との違い

| 機能 | /install-github-app | gh CLI |
|------|--------------------|----|
| 認証 | OAuth App | PAT or OAuth |
| 操作 | Claude経由 | 直接コマンド |
| 柔軟性 | 自然言語で指示 | コマンド覚える必要 |
| 制限 | App権限に依存 | トークン権限に依存 |
