## 言語設定

```markdown
**日本語での対応**
- すべてのやり取りを日本語で行ってください
- 技術的な内容も日本語で説明してください
```

---

## Gitポリシー（最重要）

```markdown
**絶対に`git add`を実行してはいけない**
- ユーザーが「git commit」と言った時、
  絶対に`git add`を実行しない
- ステージングされている変更のみでコミットする
```

なぜ？ → 意図しないファイルをコミットさせない

---

## コミットメッセージ作成手順

```markdown
**コミットメッセージ作成時の必須手順**
- 必ず`git diff --cached`で変更内容を確認
- ブランチ名やファイル名からの推測ではなく
  実際の変更に基づく
```

---

## 言語別開発ポリシー: Laravel/PHP

```markdown
- すべてのコマンドは必ずDockerコンテナ内で実行
- 正しい: `docker compose exec php php artisan migrate`
- 間違い: `php artisan migrate`
```

---

## コメント記述ルール

```markdown
**禁止される表現の例：**
- 「〜を駆逐」「〜を撲滅」などの過激な表現
- 「〜かもしれない」「〜だろう」などの曖昧な表現
- ユーモアや皮肉を含む表現
```

---

## 人名表記ポリシー

```markdown
**漢字表記が確実にわかる場合のみ漢字を使用**
- 悪い例：「石川正幸」（Masayuki Ishikawaとしか記載がない場合）
- 良い例：「Masayuki Ishikawa」
```

なぜ？ → AIが漢字を推測して間違えることがある

---

# 効果があった設定

- git add禁止 → 事故防止に効果大
- 日本語強制 → 回答が安定
- Makefile強制 → 環境再現性向上

---

# 失敗した設定

- 細かすぎるルール → 守られないことも
- 矛盾するルール → 混乱の元
