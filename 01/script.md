## 2. カンファレンスとは（10分）

### なぜカンファレンスに行くのか

- 最新の技術トレンドがわかる
- 同じ技術に興味を持つ人と出会える
- モチベーションが上がる
- 会社の外の世界を知れる

### 参加形態

#### 現地参加

- ネットワーキングができる
- ブース巡りが楽しい（ノベルティもらえる）
- 懇親会で交流できる
- 旅行気分も味わえる（地方開催の場合）

#### オンライン参加

- 移動コストなし
- アーカイブで後から見られる
- 複数トラックを並行視聴できる
- 気軽に参加できる

#### スピーカー参加

- 登壇経験になる
- 参加費無料になることが多い
- CFP（Call for Proposals）をチェック
- 5分のLTからでも始められる

## 3. オススメカンファレンス紹介（20分）

### 言語・フレームワーク系

#### PHPカンファレンス（12月）

- 日本最大のPHPイベント
- 毎年12月に開催
- 初心者向けから上級者向けまで幅広いセッション
- https://phpcon.php.gr.jp/

#### Laravel JP Conference（不定期）

- Laravel特化のカンファレンス
- 実践的な内容が多い

#### Go Conference（春・秋）

- Go言語コミュニティ主催
- 年2回開催
- https://gocon.jp/

#### RubyKaigi（5月頃）

- Ruby最大のイベント
- 国際カンファレンス（英語セッションも多い）
- 地方開催が多い（松山、三重、沖縄など）

#### TSKaigi（春）

- TypeScript特化
- 2024年から始まった新しいカンファレンス
- フロントエンドだけでなくバックエンドも

#### PyCon JP（9-10月）

- Python
- データサイエンス、機械学習系のセッションも多い

### クラウド・インフラ系

#### AWS Summit（春）

- AWS最大イベント
- 無料で参加できる
- 幕張メッセで開催
- ブースがたくさん、ノベルティも豊富
- https://aws.amazon.com/jp/events/summits/

#### AWS re:Invent recap（12月）

- ラスベガスのre:Inventの振り返りイベント
- 新サービスの解説
- 日本各地で開催

#### CloudNative Days（春・秋）

- Kubernetes、クラウドネイティブ技術
- 実践的な内容が多い

#### July Tech Festa（7月）

- インフラエンジニア向け
- 7月開催

### 総合系

#### Developers Summit（2月）

- 通称デブサミ
- 総合デベロッパーイベント
- 翔泳社主催
- キャリア系のセッションも

#### YAPC::Japan（不定期）

- Perl発祥だが今は幅広い技術
- コミュニティ感が強い
- 地方開催も多い

### 海外カンファレンス（一度は行きたい）

#### AWS re:Invent（ラスベガス、11-12月）

- AWS最大のイベント
- 5万人規模
- 新サービス発表
- 会社で行ける機会があれば

#### KubeCon（各地）

- Kubernetes
- 北米、ヨーロッパ、中国で開催

#### GitHub Universe（サンフランシスコ）

- GitHubの年次イベント
- 新機能発表

## 4. 参加のコツ（10分）

### 事前準備

- 見たいセッションをリストアップしておく
- タイムテーブルを確認（複数トラックある場合）
- 名刺を用意（現地参加の場合）
- 充電器を忘れずに

### 当日

- 早めに到着（人気セッションは席が埋まる）
- メモを取る（後で振り返れるように）
- SNSで実況（#ハッシュタグをチェック）
- 懇親会に参加（これが一番大事かも）

### 事後

- ブログにまとめる（自分の理解が深まる）
- 社内共有（チームに還元）
- 資料のアーカイブを確認（後から見直せる）

### 情報収集方法

- connpass - https://connpass.com/
- Doorkeeper - https://www.doorkeeper.jp/
- Peatix - https://peatix.com/
- 各カンファレンスのTwitter/X
- テック系メディア（Publickey、Zennなど）
